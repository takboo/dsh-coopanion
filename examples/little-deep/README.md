# 小湛实验性 API 2 角色包

使用已确认的集中工作／汇报、提问和审批表演。此包是实际接入候选，安装与真实会话结果另行记录。

从仓库根目录执行 `node scripts/build-little-deep.mjs /new/path/little-deep.zip`，再从角色面板导入 ZIP。源码入口依赖仓库内的共享控制器；使用该构建命令将它们及 Livelings 打成包内模块。输出拒绝覆盖既有文件。

已通过实机工作流程的 0.0.2 以[固定 ZIP 摘要](../../docs/design/runtime-baseline.md)为准。源码继续演进后重新构建属于新候选，不自动继承该固定包的验收。

清单的 `extensions.dsh-coopanion.state=1` 选择接收宿主的最小状态快照。工作身份跨工具切换保持，提问／审批以完整身份等待和结算。旧宿主忽略该扩展时，角色降级使用原神态词，不凭动作词制造待处理问号或感叹号；既有 API 2 角色不接收新增字段。

角色使用宿主 step 作为唯一动画时钟；支持换色、缩放、点击、悬停抚摸、拖拽、重力掉落与有界投掷。工作中触摸会短暂展开回应，之后续接原工作身份。初始朝向与已确认样片一致，问号本身不镜像。普通回复回安静陪伴。本实验不启用自主行走、完整生活抚摸分镜、隐身或目标完成庆祝候选；原生聊天、请求处理和完成判断仍由宿主拥有。

0.0.2 是实装反馈后的候选：集中开场潜水，工具工作保持完整的专注姿态；其间思考与执行用眼神、前倾及划鳍区分，公开汇报或新工作段再切换大轮廓，不按沉默秒数判断长考。角色包的可选 `extensions.dsh-coopanion.ui` 声明气泡和面板的颜色、边框、圆角及阴影，宿主保留正文、选项、字号与操作。工作主线与请求续接已获实机测试通过；其他交互／皮肤细节按当前设计入口的范围分别确认。

不读取会话正文、工具参数／输出、推理或凭证；没有网络、Node 或审批提交权限。`source.json` 记录打包输入摘要，许可见同包 LICENSE、LICENSE-LIVELINGS 与 THIRD_PARTY_NOTICES.md。运行环境及实际验证从仓库 docs/design/README.md 接手。
