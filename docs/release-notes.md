# v0.4.1

接入 Harness 的公开 `agent/assistant-stream` 和 `agent/status` 事件，分别驱动思考、回复、工具工作及等待确认。思考标记持续显示；新任务唤醒休息中的角色；流式回复保留可见前缀、停顿和嘴部动作，完成时不重新打字。上游身体的摸头、戳一下、叫醒及拖拽事件直接用于互动。

右键菜单、聊天和会话选择统一为描边卡片与角色配色。会话显示真实提问、最近提问、路径、时间和可区分短编号，支持搜索及键盘操作；已加载旧会话从公开历史恢复标题。鼠标操作结束后，迟到的拖拽反馈不会关闭新开的聊天面板。

macOS 状态栏共享当前会话、任务状态、角色配色、休息、显示 / 隐藏与音效状态；状态文字与缩略图跟随变化，菜单支持切换会话与操作桌宠。走动及任务提醒使用 Harness 持久设置，桌宠、状态栏和设置页双向同步。

增加实时流、同项目会话、休息唤醒及原生状态栏同步测试，并新增 macOS 原生 CI。支持 DSH 0.2.0-rc.2 与 0.2.1-alpha.1，安装包为 `dsh-coopanion-0.4.1.tgz`。

# v0.4.0

动画和角色系统改为直接复用 Coopanion 的 AGPL 运行时。大肥鱼恢复原生网格变形、弹簧动作、动态五官、拖拽 / 抛掷物理和八套配色；说话使用描边气泡、逐字显示、嘴部动作和合成音效。

角色包统一为 `figure.json` API 2 ZIP，支持动作预览、配色 / 多轴换装、角色切换和重启保存。旧 `.dshpet` v1、Canvas 关键帧引擎、旧 schema 和转换工具全部移除。此版本为破坏式更新，旧角色选择重置，需重新制作或导入 API 2 包。

Harness 会话、聊天、审批提醒、原生设置和透明置顶窗口继续保留。角色脚本在无网络的 opaque-origin iframe 中运行，不开放 Node 或 Electron 桥。

移除角色旁常驻的会话气泡、悬浮按钮、状态装饰和底部名称标签。双击角色打开聊天，再点击当前会话切换对话；右键角色打开菜单。

展开的菜单和面板保持位置稳定，避免随角色呼吸移动；说话气泡继续跟随角色。动画调度限制待处理帧，避免慢速渲染时积压输入。

组合程序改为 AGPL-3.0-or-later；保留原 MIT 署名及上游素材的独立权利声明。菜单可下载当前程序的完整对应源码。

支持 DSH 0.2.0-rc.2 与 0.2.1-alpha.1；请使用生成的 `dsh-coopanion-0.4.0.tgz` 安装。此工作不自动发布 GitHub Release 或 npm。
