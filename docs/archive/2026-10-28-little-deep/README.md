# 2026-10-28 小湛迭代归档

当前约束、下一步和用户最新反馈只从[设计入口](../../design/README.md)读取。本页解释旧讨论与对照，不新增实施任务。

## 本轮决定

| 阶段 | 结果 |
| --- | --- |
| Harness thinking 尾巴 | 用户要求明显摆动、两种尾巴都实心；后续统一采样和尾鳍刚性旋转 |
| 官方 logo 比例 | 用户指出尾巴像强行拼接；改用卷起双叶、短弯尾柄和连续连接曲线，比例仍待体验 |
| 眼睛选择 | 用户看过 B／C 动态后选 B 大小眼；弯弯白斑不作为当前眼睛方向 |
| 藏尾巴初次探头 | 用户明确认为尾柄旁多出的头很奇怪，已撤掉；不恢复该造型 |
| 归档时的藏尾表演 | 沿用原本鲸鱼缩身试探，当时尚未得到用户体验确认；抚摸余韵未实施 |
| 工作分镜探索 | [6.2 秒串行长版](storyboard-long-v0/README.md)被短版取代；保留文档、源码和测试原字节快照，不再强求对视 |
