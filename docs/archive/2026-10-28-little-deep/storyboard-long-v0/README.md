# 已取代的工作分镜长版

此目录保留 2026-10-28 探索阶段的 6.2 秒串行分镜。它曾将收势、视线回中、侧倾、描画及进入等待逐段串联，并保留单看 C 的局部版本。

用户反馈实际观感更像“一怔、产生疑问、睁眼”，没有明确对视感，且整段偏长。随后确定先做约 1.5 秒的疑问浮现版，动作交叠，不强求对视。当前方案与后续工作只从[设计入口](../../../design/README.md)读取。

这里的五份 `.txt` 是清理前文档、控制源码、页面和测试的原字节快照。扩展名用于避免将其当成当前可运行入口；内容中的相对路径按 `manifest.json` 的 original 字段解释，不在归档目录直接运行。快照来自未提交的探索工作区，基线提交及 SHA-256 见 [manifest.json](manifest.json)。

| 快照 | 原用途 |

| [分镜规范](little-deep-work-v0.md.txt) | 旧意图、逐段时间及当时接手状态 |

| [页面控制](storyboard.js.txt) | 旧播放范围、绘制及控制逻辑 |
| [页面](storyboard.html.txt) | 旧四格和连续样片界面 |
