# 纯代码鲸鱼交互原型

一次性设计原型，用于比较三个 DeepSeek 概念鲸鱼的形象与鲜活感，等待用户观感反馈。源码、曲线与动画均为本次原创，无图片、外部字体、依赖或模型连接；借鉴 Livelings 将运动材质与专属反应一起设计的方法，未复制其代码或角色资源。

从仓库根目录运行：

```bash
python3 -m http.server 4186 --bind 127.0.0.1 --directory docs/design/art-workflow/whale-code-prototype-v1
```

打开 `http://127.0.0.1:4186/`，也可直接用浏览器打开 `index.html`。

底栏或键盘左右方向键切换 `?variant=all|round|swim|tail`；滑块调整身体大小，日光／夜色比较背景，减少动态保留状态表达。思考／完成／睡眠均为手动演示。指针靠近驱动视线，轻戳、悬停慢摸及拖动可交互；拖动松手后回到预览中心，不代表产品放置行为。

- 团团：圆润短身，身体回弹，尾巴带一点迟滞。
- 游游：流线蓝鲸，缓慢游动，单侧脸与腹部线条。
- 尾尾：竖向身体，思考时潜下去露出摆动的尾巴，参考用户提供的 Harness 思考尾巴意象。

本页不接入 API 2，不修改 NPC、原生窗口或已有角色。浏览器检查只确认原型可显示、可交互；形象与 LIVE 是否成立由用户实际体验判断。后续若选定方向，需要重新按产品接口实现并验证。

研讨背景见[白板](../../companion-art-whiteboard.md)。
