# 小湛回复结束／目标完成分镜 v1

2026-10-30，当前候选，尚待用户观看。已有 0.4.15 插件 + 0.0.2 角色包的工作／请求基线保留。本轮仅制作独立浏览器分镜与样片，未更新实机角色包。

## 意图、固定项与能力

普通回复结束表示“这一轮说完了”，轻收势后回生活；真正目标完成表示“这件事做完了”，开心展开、送一次小水花，再落回生活。只消费共享 CompletionTracker 已给出的 reply／goal-progress／completed 分类，不能从文字、工具成功、批准或中途 goal/change 推断完成。完整 session + goal id + revision 识别一次完成，round 变化不重播同一目标版本。

沿用原蓝鲸、白腹、额顶缺口、B 大小眼及实心尾鳍；固定机位、尺度与左朝向，不增加头部、成功勾或画内说明。已有能力为完整鲸鱼 morph、眼形、lookAt、整体 lean、hover、小鳍、摆尾和原 spout 的 drop 粒子。本轮补局部收尾时序与可取消的一次水花；不新增行走、关系成长或系统窗口行为。

## 打断与退出

选择新工作、?、! 或等待请求时来了新工作的路线，并可选喷水前（5.2 秒）、庆祝中（6 秒）、收尾时（7.8 秒）打断。每次自动路线等待 3 秒后明确模拟结算；手动入口始终按完整当前请求身份结算，多请求未全结算时继续等待。

新工作立即取消未播庆祝，保留当前姿态接入新工作段。?／! 沿用已确认的身体与符号接管；退出后进入最新工作或新的生活计划，不恢复旧庆祝或补发水花。已出现的粒子自然衰减。完成事实在请求等待中到达时也不排队补播。

页面隐藏冻结段落、粒子和样片时钟；恢复不重播出场。换色保留姿态和进度。减少动态保留轻收势／开心神态、只出两粒水花，压低倾斜与抬起。手动接管会停止后续模拟 cue，避免旧分镜覆盖用户操作。

## 观看问题与验证边界

遮住画外文字后，能否区分普通结束与真正完成？一次小水花是否适度？回生活是否自然？在三种时刻插入新工作、?、!，是否接得住当前余势，且退出后没有旧庆祝回流？

机制、浏览器与产物身份记录见[工作区与本轮验证](../workspace-maintenance.md)。本候选不等于宿主或实机目标完成已经接入、通过；用户观看反馈尚待进行。早期 v0 与旧结构回放只用于[历史追溯](../../archive/2026-10-30-completion-handoff/README.md)。

实机接入还须核对完成所属来源的送达：现有宿主在所有工作空闲后会将表演来源切回选中的聊天，会导致后台已结束工作不再是该快照的来源。不能仅因 work.outcome 字段已存在，就认定后台完成一定能送到角色。该边界应在接入阶段用真实目标会话验证，本轮不改宿主投影。
