# 小湛工作分镜 v0

更新于 2026-10-28。按[角色产出工作流](../character-production-workflow.md)制作。本轮当前样片为 **W03 疑问浮现**，核心出场约 1.5 秒，随后保持等待。此前串行长版已归档，当前规范以本页为准。

## 意图与验收目标

小湛有件事想问你，稍微停一下，提出疑问，等你回应。可以保留“一怔、睁眼、疑问浮现”的感觉，神态偏好奇、稍有犹豫；避免把正常提问演成任务失败或持续茫然。

**不强求对视。** 眼睑和视线的小幅变化只辅助神态，不承诺观众会读成“看向我”。明确指向用户的回应可在后续轻戳、靠近和抚摸场景单独验证。

触发事实来自真实待处理提问，审批可用同一身体动作配感叹号比较。当前[视觉样片](../art-workflow/whale-little-deep-v3/storyboard.html#preview)仍是固定分镜，不接入 Harness 或结算请求。

## 角色和画面

固定造型以[当前设计入口](../README.md#固定造型)为准，全段复用现有鲸鱼轮廓、白腹、B 大小眼基准和实心尾鳍。采用固定机位及尺度，配色切换只作同造型对照；镜内全色盘渐变尚未实现。

画内保留角色和无底牌图形附属物。问号位于左侧头前，沿有机笔画逐步形成，弯钩先画、圆点最后落下，并有独立轻颤。时间、阶段名和说明放在画外。

## 交叠时序

分镜编号和节拍用于说明动作关系，不要求逐项串行演完。出场不包含额外的工作参照片头，等待也不计入一次性表演时长。

| 时间 | 身体与神态 | 符号与承接 |
| --- | --- | --- |
| 0–0.25 秒 | 稍微一怔，划鳍与身体横移减弱；眼睑同时逐渐打开 | 保留原有动势，侧倾提前进入，不等睁眼完成 |
| 0.15–1.05 秒 | 整体侧倾约 12°，尾部稍后跟随；漂浮继续 | 头前逐笔画出问号，圆点最后落下；问号自身轻颤 |
| 1.05–1.5 秒 | 身体稍回正，眼睑逐渐放松 | 符号保留，颤动减弱；衔接安静等待，弹簧余势自然落定 |
| 1.5 秒以后 | 低幅摆尾、呼吸、漂浮及偶发眨眼 | 等待真实处理，不重播出场、不撤掉待处理标记 |

当前控制目标在约 1.05 秒完成问号，约 1.5 秒接入等待；身体允许保留少量惯性余韵。时序与采样时刻由 [storyboard-performance.js](../art-workflow/whale-little-deep-v3/storyboard-performance.js)维护，三张参考帧来自同一表演的 0.12／0.70／1.5 秒。

## 实现能力与边界

| 表演 | 当前实现 | 边界 |
| --- | --- | --- |
| 收势、睁眼和侧倾交叠 | 同一 Actor 保留位置与速度；插值控制 `rootX`、`lean`、`tail`、`fin` 与眼形 | 只验证固定分镜，任意任务姿态的接入待补 |
| 神态中的视线变化 | `lookAt(x, y)` 平滑改变双眼整体偏移，保留 B 大小眼基准 | 无独立瞳孔，不将回中等同于对视 |
| 约 12° 侧倾 | `lean.target` 峰值约 0.22 弧度，随后放松 | 整只鲸鱼旋转，没有独立歪头或正脸转身 |
| 问号／感叹号 | 路径长度控制笔画生长，最后落点，头前锚点及独立颤动 | 角色完整形变中的附着、退场和正式角色接口待补 |
| 漂浮和眨眼 | 复用引擎呼吸、漂浮及原生眨眼 | 长期生命感、实际小尺寸及系统偏好需要体验 |
| 配色和符号对照 | 切换时保留当前进度和姿态 | 全色盘镜内渐变待补 |

绘制与查看控制见 [storyboard.js](../art-workflow/whale-little-deep-v3/storyboard.js)。重播和拖动进度会按同一种子与固定步长重建姿态；自动推进只使用一个实例。页面隐藏暂停推进，恢复不补播。减少动态时默认展示完成姿态，手动播放降低侧倾／划鳍／横移，关闭颤动。

## 本轮观看问题

1. 疑问是否更早成立？收势、睁眼和侧倾的交叠是否自然？
2. 约 1.5 秒是否简洁，同时保留逐笔成形、轻颤和余韵？
3. 神态是否好奇、稍有犹豫，而非出错或持续迷茫？
4. 头前位置、笔画风格及侧倾幅度在实际尺寸下是否清楚且不过分？

短版已实现，尚待用户体验确认。下一步先收敛这些问题，再补真实结算退场及交互接管；随后复做审批场景。旧长版和早期“必须看向用户”的假设从[归档说明](../../archive/2026-10-28-little-deep/storyboard-long-v0/README.md)追溯。

## 后续场景与事实边界

| 场景 | 待完成内容 |
| --- | --- |
| 普通回复 | 思考、工具工作、生成回复及普通收势；不庆祝中间回合 |
| 审批 | 身体表演复用与感叹号区分，真实决定后的承接 |
| 提问 | 当前出场的体验调整，真实答复／取消后的符号退场和继续 |
| 目标完成 | 只按共享完成判断选择开心展开及喷水 |
| 异常与停止 | 回合错误、阻塞／输出上限、中断及用户停止分别表达 |

请求实际结算后才收起待处理标记；打开或关闭提示不等于处理。并存请求保留各自身份，重复同步不重播；新事件与用户操控从当前姿态接管，旧动作不延迟补播。上述真实交互与事件路径仍待接入，不由固定样片证明。
