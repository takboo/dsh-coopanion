# 小湛实装反馈后的交互与工作候选

2026-10-29，用户反馈首轮 API 2 包交互缺失、全程尾巴、方向不一致及宿主 UI 画风不合。旧分镜的用户确认保留；本页记录 0.0.2 的身体与交互设计；工作流程后来已获实机反馈通过，固定包及范围以[基线索引](../runtime-baseline.md)为准，其他交互和皮肤细节仍单独评审。

| 场景 | 起势、持续与退出 |

| 抚摸 | 真实悬停轨迹累计触发，完整身体舒展、眯眼、轻倾；停止后约 1.3 秒余韵，再续当前阶段；表演反馈不等于关系成长 |
| 拖拽 | 指针拥有身体位置，完整身体与小鳍响应，工作续点暂停；新 ?／! 保留完整身份和标记 |
| 掉落与投掷 | 松手保留当前位置，统一 up 输入允许有界速度，重力连续落地、轻回弹，之后续当前工作；取消及切屏放置清速度 |

工具段一旦建立，就保留完整工作轮廓；其间 focus 以收眼、停鳍和轻抬头表示复核，tools 以前倾、划鳍表示执行。公开汇报或新工作身份才结束这段大轮廓，源 stage 始终即时更新。不用沉默秒数判断长考，也不为每次工具往返安排潜入浮出。此编排仅由实验包选择，原工作／生活并排样片继续保留已确认版本。

初始身体固定为样片的左朝向；API facing=-1 左／+1 右。绘制与命中使用同一变换，符号仅镜像锚点。换角色不继承前一个身体的偶然朝向。

角色 UI 先提供声明式皮肤：小湛用浅蓝底、蓝灰字、较细蓝边、圆角和弱阴影候选。气泡、选项及操作仍为宿主 DOM，继承字号、键盘、可访问性和真实请求逻辑。完整换布局和独立尾巴图形不在此版本。

用户给出的 `session-e57e4a14-b092-46c8-aca1-659e39cbc740` 只读核对为 415 事件、两回合实际工作约 603／129 秒、62 次工具和 3 段公开文字，无正式提问或审批。只在公开输出及请求浮出的首轮映射确实使大多数时间只剩尾巴。记录只导出元数据，原会话正文与推理未进入角色或报告。
