## 固定造型与本轮变化

小湛的蓝色、白腹、额顶缺口、大小眼、实心尾鳍、短弯尾柄、朝向和物理参数全部沿用原 character.js。只新增本地表演动作、喷流效果与彩虹绘制，没有导入 Bloop 的鲸鱼造型、海面场景或打包在 HTML 内的另一份引擎。

喷水使用三条圆头弹性曲线：左右浅蓝喷流、中央浅色水芯。压力采用弹簧起落，独立水滴按初速度和重力运动，经过顶点后自然下落；没有把水滴固定停放成图案。庆祝将跃起、倾斜、兴奋神态、喷水、彩虹和回落水花编在一次动作内。现有尾鳍摆动和小鳍控制支撑身体动作，不增加身体零件。
